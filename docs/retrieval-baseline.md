# 固定检索与问答基准

阶段 2 只验收关键词检索，以下自然语言答案和引用质量留到阶段 3；不能用演示答案算通过。

| 用途 | 输入 | 阶段 2 检索词 / 预期 | 阶段 3 预期 |
|---|---|---|---|
| 正常回答 | Java 21 虚拟线程适用什么任务？ | 导入并批准 JEP 444；搜 `virtual threads` 命中 | 根据证据回答并定位引用 |
| 中文检索 | 虚拟线程 | 批准中文笔记后命中；待审核时不命中 | 中文查询召回英文/中文相关证据 |
| 精确 API | Class.forName | 中文验收笔记中命中原样 API | 保留类名及上下文引用 |
| 资料不足 | 系统未导入的 FooFramework 如何调优？ | 无结果，不伪造回答 | 明确资料不足，建议补充导入 |
| 版本冲突 | Java 17 可否使用 Java 21 虚拟线程 API？ | `version=17` 不命中仅标注 21 的资料 | 澄清版本并说明证据范围 |
| 代码示例 | 给出资料中的虚拟线程示例 | 正文保留缩进与代码，未执行 | 来源示例与 AI 生成示例分别标注，均不得暗示验证 |
| 框架比较 | Spring Boot 与 Quarkus 哪个更快？ | 无证据时无结果 | 不跨版本/环境比较数据；区分事实、观点与推断 |
